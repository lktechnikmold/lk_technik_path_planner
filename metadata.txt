about=Plugin for importing and exporting guidance and field data for agricultural steering systems.
    The export format is chosen automatically from the selected terminal (ISOXML v3/v4, John Deere Gen4, AgGPS, CNH CN1).
    Features a field catalogue (Felder.csv) as the single source of truth, a structured selection tree (Customer → Farm → Field), field management (add, rename, delete, zoom, dropdown selection), optional contour segments, curve densification/extension, and automatic track creation from field boundaries (straight lines and curves, parallel offset, name prefix).
    Runs on QGIS 3 (from 3.16) and QGIS 4.

    - New track creation tab: guidance tracks from field boundaries (straight lines/curves, split at corners, exactly on the boundary), inward offset without shortening, tracks along shared borders, name prefix and contour segment.
    - Holes in field boundaries and obstacles (ISOXML, Gen4).
    - Name for area obstacles (ISOXML, Gen4, AgGPS).
    - Zoom to field and delete several fields at once (right-click in the export tree).
    - Overwrite confirmation on export and import; "please wait" message during import/export.
    - Contour segments also for Fendt Vario Terminal INT 01, Valtra Smart Touch, MF Datatronic 5 and ISOXML v4.
    - Terminal list cleaned up and extended (LACOS LC:ONE, Intelli View 12); default terminal ISOXML v4.

    - White label buffer, alphabetical field order, column order of area obstacles.
    - Fix: a second import into the same target folder doubled all data.
